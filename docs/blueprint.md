# **App Name**: Giftopia

## Core Features:

- Gift Catalog: Browse gifts by category (e.g., occasions, recipients, price range).
- Product Pages: Detailed view of each gift with images, description, and price.
- Add to Cart: Add selected items to the shopping cart.
- Shopping Cart: View, modify, and checkout the selected items in the shopping cart.
- User Authentication: Login and registration functionality for user accounts.

## Style Guidelines:

- Primary color: Soft red (#F2D7D5) to create a warm and inviting atmosphere.
- Background color: Very light desaturated red (#F8F1F1) provides a soft backdrop.
- Accent color: Gold (#E5B849) to bring festive elegance to CTAs and accents.
- Font pairing: 'Playfair' (serif) for headlines to evoke an elegant and fashionable feel and 'PT Sans' (sans-serif) for body text.
- Use high-quality icons related to gifts, shopping, and user accounts.
- Clean and intuitive layout with a prominent search bar and clear navigation.
- Subtle animations and transitions for a delightful shopping experience.
